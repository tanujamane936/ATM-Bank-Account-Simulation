# ATM Management System using Python 🏧

## 📌 Project Overview

The **ATM Management System** is a Python-based project developed using Jupyter Notebook. It simulates basic ATM operations and helps users perform common banking transactions through a simple Python program.

This project is designed to demonstrate Python programming concepts such as variables, conditional statements, loops, functions, and user input.

## 🚀 Features

- 🔐 User authentication / PIN verification
- 💰 Check account balance
- 💵 Withdraw money
- 💳 Deposit money
- 🔄 Perform multiple transactions
- 🚪 Exit the ATM system

## 🛠️ Technologies Used

- **Python**
- **Jupyter Notebook**
